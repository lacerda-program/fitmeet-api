### Quick Start Commands

#### Windows
```powershell
# Start database containers
docker-compose up -d

# Verify status
docker-compose ps

# Start Spring Boot application
gradlew.bat bootRun

# Use helper script
.\db-helper.bat start
.\db-helper.bat status
.\db-helper.bat logs
.\db-helper.bat stop

# Initialize S3 bucket
.\init-s3.bat
```

#### Linux/Mac
```bash
# Start database containers
docker-compose up -d

# Verify status
docker-compose ps

# Start Spring Boot application
./gradlew bootRun

# Use helper script
chmod +x db-helper.sh
./db-helper.sh start
./db-helper.sh status
./db-helper.sh logs
./db-helper.sh stop

# Initialize S3 bucket
chmod +x init-s3.sh
./init-s3.sh
```

### Migrations Auto-Run
When the Spring Boot application starts:
1. It connects to PostgreSQL
2. Liquibase automatically:
   - Creates all required tables
   - Creates foreign key relationships
   - Populates seed data (Activity Types)
   - Tracks migration history

### Next Steps
1. Ensure Docker is installed and running
2. Navigate to project root directory
3. Run: docker-compose up -d
4. Run: gradlew.bat bootRun (or ./gradlew bootRun on Linux/Mac)
5. Application will automatically initialize the database
6. Access API at http://localhost:8080
7. Swagger UI at http://localhost:8080/swagger-ui.html

### Database Tables Structure
1. users - User accounts (UUID PK, email/cpf unique)
2. activity_types - Categories (5 pre-loaded types)
3. activities - User activities (with type FK, creator FK)
4. activity_addresses - GPS coordinates (latitude/longitude)
5. activity_participants - Enrollment tracking (user + activity)
6. achievements - Achievement definitions (XP requirements)
7. user_achievements - User achievement records
8. preferences - User settings (theme, notifications)

### Troubleshooting Tips
- Container health check fails: Wait 10-15 seconds and try docker-compose ps again
- Port already in use: Change port in docker-compose.yml and application.yaml
- No S3 bucket: Run init-s3.bat or init-s3.sh to manually create
- Migration fails: Check Spring Boot logs for liquibase errors
